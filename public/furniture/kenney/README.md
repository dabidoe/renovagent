# Studio furniture models

Twelve original Kenney Furniture Kit models, licensed CC0 1.0. These are illustrative 3D assets, not exact retail products or measured furniture.

- Creator and original pack: https://kenney.nl/assets/furniture-kit
- Redistribution source: https://github.com/laanlabs/openPlan3D/tree/98f9cb467e4045c6abc5d9880ada1f03dff50c68/static/models
- Included original license: furniture-kit-License.txt
- Pinned source revision, file sizes and SHA-256 hashes: provenance.json

Renovagent normalizes the meshes to explicit, editable concept dimensions. It changes display colours in the browser and uses them in a proposed room layout. No product availability, price or fit is implied. Attribution is appreciated by the creator; included here voluntarily.
