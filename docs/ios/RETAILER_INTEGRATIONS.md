# Retailer imports and purchase preparation

**Phase 0 proposal · November 10, 2026**

Treat retailer sharing as a way to save a candidate. The app helps the user connect that candidate to a physical change, verify its identity and relevant specifications, obtain contractor feedback, and prepare a list for manual checkout. Launch requires no merchant account integration, crawling, SDK, affiliate identifier, or payment code.

## Share Extension intake

1. Add a signed iOS Share Extension using `com.apple.share-services`. Declare one web URL and support plain text only to capture a single HTTPS link when the host app supplies text. Use `NSItemProvider` and `UTType.url`/text representations, display a bounded confirmation, and handle absent data and cancellation. A Safari web-page preprocessing script is unnecessary. [Apple Share Extension guide](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/Share.html) · [Activation keys](https://developer.apple.com/library/archive/documentation/General/Reference/InfoPlistKeyReference/Articles/AppExtensionKeys.html)
2. Parse with Foundation URL APIs. Require HTTPS, a valid host, no user information, no control characters, and a bounded URL length. Reject malformed, unsupported or ambiguous input with an explanation. Show the domain and treat host-supplied titles/text as unverified data. Preserve variant and store parameters unless documented safe to remove. Strip known tracking keys only under explicit tests. Do not infer merchant or SKU from a substring match. Opaque short links can stay unclassified and be opened only on explicit user action. Session-bearing or signed links should be excluded from exports pending user replacement. The extension makes no network requests or redirect probes.
3. Commit a small immutable inbox record to the shared App Group using an atomic write and a unique import ID. Include source URL, safe display URL/domain, optional bounded user note, capture timestamp and payload schema version. Finish the extension request after the write. No requirement to launch the main app or hand out project database access. The next launch or foreground drains records into a local pending inbox, dedupes normalized identity without merging distinct variants, and asks the owner which project or requirement to attach. A failed attachment remains retryable and replays once. Handle a full inbox and concurrent deliveries. [App Groups](https://developer.apple.com/documentation/xcode/configuring-app-groups) · [Atomic shared data guidance](https://developer.apple.com/library/archive/technotes/tn2408/_index.html)
4. Keep manual paste and manual model/spec entry in the main app. Test retailer iOS product screens, Safari, and text-forwarding hosts on physical devices. A merchant website or developer portal does not establish what its current iOS share sheet emits. No retailer app payloads were captured for this audit.

**Existing sources:** reuse the [project reference schema](../../packages/contracts/src/facts.ts) and [notebook URL/content contract](../../packages/contracts/src/project-notebook.ts) as domain inputs once a link is attached. The [existing studio find path](../../apps/api/src/studio-plans.ts) provides a precedent for storing references without fetching them. An inbox link has neither a catalog identity nor a verified price. **Complexity: medium, 3–5 engineer-days** including signed two-target testing and recovery cases. Dependencies are Apple Foundation, Uniform Type Identifiers, the Share Extension SDK and App Groups. Confirm team signing/entitlements. Merchant marks, page copy, photos and product feeds have separate rights. A user-supplied link does not grant redistribution rights to its page contents.

## From link to reviewed line

Use [catalog contracts](../../packages/contracts/src/catalog.ts), [matching](../../packages/core/src/commerce/matching.ts), [planning](../../packages/core/src/commerce/plans.ts) and [checkout grouping](../../packages/core/src/commerce/checkout.ts) as shared domain primitives. **Medium–high** for local, private selections because the existing plan builder ranks priced catalog offers and the MVP accepts an owner-selected, potentially unpriced variant. Add a typed adapter rather than inventing a matching price or populating the global catalog.

- Record manufacturer model, merchant variant/SKU, exact relevant dimensions and connection requirements with evidence, quantity and who supplies it. Contractor remarks can establish a condition for review. Missing critical fields block preparation. A candidate's plan preview is schematic.
- An optional amount records currency in minor units, units or pack, source, observation time and known exclusions. Ask for a current check at checkout. Local selection may remain unpriced and have no subtotal. Preserve trade prices and quotes privately unless explicitly shared. A different SKU, price basis or critical dimension can require renewed review.
- Export only current reviewed lines and list omissions and reasons. Show buyer, merchant, exact variant, quantity and verification checklist. Open the link with the user's explicit tap. No call creates a cart on a merchant server, submits an order or handles payment.
- Any future paid/connected supplier adapter needs approved written access, exact data terms, rate limits, geographic/store/account coverage, test credentials and exception handling. UCP/ACP specify transport or checkout contracts, not supplier access. Validate authorized lookup/quote/handoff before considering any separately approved purchase workflow.

## Acceptance evidence to collect

Test Safari and the installed versions of Lowe’s, Home Depot and one additional retailer or local supplier in the pilot. Record device/OS, host/version, product variant, raw representation type, whether Renovagent appears, whether the saved target is correct and whether paste recovers unsupported cases. Exercise URL item, text containing one URL, zero/multiple URLs, signed URL, short link, invalid scheme, repeated save, distinct variant query, forced termination immediately after save, full inbox, missing group entitlement, and explicit cancellation. Verify zero network activity during import and no link, private quote or source media in diagnostics. The reviewed PDF/CSV must exclude a stale or unreviewed line even if the link still opens.
