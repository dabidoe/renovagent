# Studio local-code source brief

November 2, 2026. UI-only; no provider calls, database writes or deployment.

Plan & budget now includes a compact Local Building code card. It reads the
existing core source/requirement records, `determineCodeBasis`, `resolveLocalContext`,
`assessCode` and `assessDrainage`; no code provision text or requirement was added.
Source titles, exact locators, URLs and review needs are displayed from the package.
The real package is `philadelphia-half-bath-2026-10-27.6`, captured October 27, 2026.

The Philadelphia listing example supplies its existing reported locality explicitly;
the displayed address is the established privacy alias. Filing dates, edition
elections, building facts, measurements and technical scope remain unknown.
Arbitrary address text is never parsed or geocoded into an enforcing authority.
Unknown, conflicting, unconfirmed-boundary and outside-package locations show only
the requested coverage notice. Other studio callers can supply existing structured
`PlanningInputs`; the card does not save or promote those inputs to physical facts.

For the current studio finish scope the permit records are presented as a question,
with applicability unresolved. Explicit `new-half-bath` inputs expose the existing
core checks, actual statuses and source review limits. Missing inputs stay
`needs_input`; no more favorable status is substituted. Captured-but-unusable
coverage remains distinct from source retrieval/review status. There is no technical
release or automatic permit decision.
