# Brand artwork

- `renovagent-logo.png` is an unchanged copy of the owner's supplied `docs/pics/Renovagent Architectural Scan Logo.png`. The header displays the full original stacked symbol and wordmark.
- `renovagent-mark.png` and `renovagent-mark.svg` use a crop of the original symbol, without redrawing its geometry. The SVG is a raster-backed wrapper. Favicons in `public/` use that same source artwork. No added left panel or reconstructed wordmark.
- `muse-app-icon.png` is a 64px rendering of the installed Muse app's `Contents/Resources/AppIcon.icns`, obtained October 30, 2026. It identifies Muse beside the connection link; it is not a claim of partnership or stable hosted availability.
